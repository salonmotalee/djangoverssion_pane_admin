# Vazir FD fonts

These are unmodified official **Vazir v30.1.0 Farsi Digits (FD)** WOFF2 files.
FD renders Western digit characters with Persian numeral glyphs. The fonts are
served locally so the application does not depend on a third-party font service.

- Author: The Vazir Project Authors, led by Saber Rastikerdar.
- Official repository: https://github.com/rastikerdar/vazir-font
- Source tag: https://github.com/rastikerdar/vazir-font/tree/v30.1.0
- Source commit: `68833b2c255d96d38b517acdf327b6367e9e8d67`
- Source directory: `dist/Farsi-Digits/`

  are included in [FONT-LICENSE.txt](FONT-LICENSE.txt).
